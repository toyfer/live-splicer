# Live Splicer

AAC のライブ音源を指定位置で切り、前と後ろに曲名を付けて、ミュージック / iTunes が別トラックとして読む M4A に書き出すブラウザ完結型ツールです。処理は ffmpeg.wasm で、音源はサーバへ送信されません。

1本のファイルにチャプターや CUE を書いても、ミュージックの曲一覧は1件のままです。曲として並べるにはファイルを分けます。

## できること

- 再生位置で前後を別トラックにする
- MC などのカットを指定し、残った塊を曲名付きトラックにする
- 波形をドラッグして範囲を1曲として追加
- 無音区間を自動検出してカット候補にする
- 曲ごとに分割（無劣化 `-c copy`）し、タイトル・アルバム・トラック番号・カバーを書き込む
- zip でまとめてダウンロード
- 1本に結合する出力も残してあり、必要なら切り替え可能
- アルバム画像と共通タグ（アーティスト・ジャンル・年 など）
- 編集内容を JSON で保存・再読込（localStorage 自動保存つき）

## 使い方

1. 音源を選ぶ（ffmpeg-core の取得と解析・波形生成が走ります）
2. 再生ヘッドを境目に止める → 前の曲名と後ろの曲名を入れる →「この位置で前後をトラックにする」
3. MC を落とす場合は、その範囲をカットにして「カット以外をトラックにする」
4. 一覧で曲名を直す
5. 出力は既定の **曲ごとに分割（ライブラリ向け・無劣化）** のまま
6. 全曲で同じアルバム名を入れて「書き出す」

ミュージック / iTunes では、ファイルごとに違う曲名、**アルバム名は全曲同じ**、トラック番号は自動（`1/総数`）です。アルバムアーティストも揃えると、アーティスト名が曲ごとに違っても1枚にまとまります。

## 出力モード

| | 曲ごとに分割（既定） | 1 本結合・無劣化 | 1 本結合・再エンコード |
|---|---|---|---|
| 中身 | 区間ごとに別 M4A、タグ付き | 残した区間だけ連結 | AAC を 1 回再エンコードして連結 |
| 用途 | ライブラリに曲として並べる | 1 本で最後まで聴く | 結合部の隙間を消したいとき |
| 音質 | 元と同一 | 元と同一 | 再エンコード分の変化 |
| カット境界 | AAC フレーム境界 | 同左 | サンプル単位 |
| ミュージックの曲一覧 | 曲ごとに1件 | 1件 | 1件 |

## GitHub Pages

`ffmpeg-core.wasm` はリポジトリに置きません。main への push で Actions が取得し、`lib/fflate.mjs` と合わせて公開物へ入れます。

初回だけ **Settings → Pages → Source: GitHub Actions** を選んでください。公開先は `https://toyfer.github.io/live-splicer/` です。シングルスレッド core なので COOP/COEP は不要です。

## 実装メモ

- 波形は `-ac 1 -ar 3000 -c:a pcm_s16le` の WAV を一度だけ作り、ピークを 2200 バケットで canvas 描画
- 分割は音声だけを `-ss` / `-t` / `-c:a copy` で切り、カバーはシークしない別ステップで `attached_pic` として足す
- 空欄の年は上書きしない。曲名とトラック番号だけ各ファイルで書く
- 無音検出は波形ピークをしきい値で走査。検出しただけでは書き出さない
- zip は `fflate` の `zipSync`

## 制約

- 出力はブラウザのメモリ上で組み立てます。極端に長い音源では失敗することがあります
- 「中断」のあとは「ffmpeg を読み込む」で復帰してください
- 分割・無劣化結合は AAC フレーム境界でカットします。曲間をサンプル単位で揃えたい場合は再エンコード結合を使います
- 分かれたファイルをミュージックで連続再生しても、曲と曲のあいだの無音が完全に消える保証はありません
